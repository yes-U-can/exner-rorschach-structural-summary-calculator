## 주요 수정사항

### [Card] 정렬

[Card] 머리글의 정렬 버튼이 오름차순 정렬만 실행해, 이미 카드 순서대로 입력된 자료에서는 버튼을 눌러도 아무 변화가 없는 것처럼 보였습니다.

이제 정렬 버튼을 누를 때마다 오름차순과 내림차순이 번갈아 적용됩니다. 버튼 이름과 아이콘은 다음에 실행할 정렬 방향을 알려줍니다. 카드가 비어 있는 행은 항상 마지막에 두고, 같은 카드 안에서는 기존 행 순서를 유지합니다.

### AI 세션을 시작한 뒤 해석 도우미로 이동

채점 화면이나 참조 문서에서 [해석 도우미]를 누른 뒤 API 키를 입력해 AI 세션을 시작하면, 해석 도우미로 이동하지 않고 이전 화면에 그대로 남는 문제가 있었습니다.

이제 [해석 도우미]로 들어가는 과정에서 세션을 시작하면 선택한 언어를 유지한 채 해석 도우미 화면으로 이동합니다. 사이드바 아래의 일반 [AI 세션 시작] 버튼으로 세션만 연결한 경우에는 현재 화면을 그대로 유지합니다.

### 최신 메시지 이동 버튼

해석 도우미에서 대화의 최신 메시지보다 위쪽을 보고 있을 때 나타나는 버튼이 AI의 응답 상태도 함께 보여 줍니다. AI가 답변을 작성하는 동안에는 가운데에 맞춘 점 세 개가 차례로 움직이고, 답변이 끝난 뒤에는 아래 화살표가 나타납니다. 어느 상태에서든 버튼을 누르면 최신 메시지로 이동합니다.

움직임 줄이기를 사용하는 환경에서는 점의 움직임도 함께 줄어듭니다.

### 추천·비추천 선택 상태와 저장

AI 답변의 추천·비추천 버튼을 선택해도 선택하지 않은 상태와 차이가 작아 알아보기 어려웠습니다. 버튼 배경과 테두리는 기존 모습으로 유지하고, 선택한 엄지손가락 아이콘만 앱의 푸른색 실선 아이콘으로 바뀌게 해 현재 선택을 분명히 구분합니다.

추천 또는 비추천을 누르는 순간 평점이 저장되며, 이유 선택 창에서 [건너뛰기]를 누르면 이유 없이 평점만 유지됩니다. 이미 선택한 같은 버튼을 다시 누르면 평점이 삭제되고 버튼도 선택하지 않은 상태로 돌아갑니다. 질문과 답변 원문은 평가 정보에 포함되지 않습니다.

## 기존 계산 결과에 영향이 있나요?

없습니다. 이번 패치는 구조요약 계산식, 입력 가능한 부호, 참조 문서 본문, AI 답변 규칙을 바꾸지 않습니다. 기존 프로토콜을 다시 계산할 필요가 없습니다.
