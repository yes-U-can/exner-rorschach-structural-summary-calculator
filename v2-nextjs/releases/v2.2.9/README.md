# [2026-08-01] v2.2.9 버그 패치

## 주요 수정사항

### [Card] 정렬

[Card] 머리글의 정렬 버튼이 오름차순 정렬만 실행해, 이미 카드 순서대로 입력된 자료에서는 버튼을 눌러도 아무 변화가 없는 것처럼 보였습니다.

이제 정렬 버튼을 누를 때마다 오름차순과 내림차순이 번갈아 적용됩니다. 버튼 이름과 아이콘은 다음에 실행할 정렬 방향을 알려줍니다. 카드가 비어 있는 행은 항상 마지막에 두고, 같은 카드 안에서는 기존 행 순서를 유지합니다.

### AI 세션을 시작한 뒤 해석 도우미로 이동

채점 화면이나 참조 문서에서 [해석 도우미]를 누른 뒤 API 키를 입력해 AI 세션을 시작하면, 해석 도우미로 이동하지 않고 이전 화면에 그대로 남는 문제가 있었습니다.

이제 [해석 도우미]로 들어가는 과정에서 세션을 시작하면 선택한 언어를 유지한 채 해석 도우미 화면으로 이동합니다. 사이드바 아래의 일반 [AI 세션 시작] 버튼으로 세션만 연결한 경우에는 현재 화면을 그대로 유지합니다.

### 최신 메시지 이동 버튼

해석 도우미에서 대화의 최신 메시지보다 위쪽을 보고 있을 때 나타나는 버튼이 AI의 응답 상태도 함께 보여 줍니다. AI가 답변을 작성하는 동안에는 가운데에 맞춘 점 세 개가 차례로 움직이고, 답변이 끝난 뒤에는 아래 화살표가 나타납니다. 어느 상태에서든 버튼을 누르면 최신 메시지로 이동합니다.

움직임 줄이기를 사용하는 환경에서는 점의 움직임도 함께 줄어듭니다.

### 추천·비추천 선택 상태와 저장

AI 답변의 추천·비추천 버튼을 선택해도 선택하지 않은 상태와 차이가 작아 알아보기 어려웠습니다. 버튼 배경과 테두리는 기존 모습으로 유지하고, 선택한 엄지손가락 아이콘만 앱의 푸른색 실선 아이콘으로 바뀌게 해 현재 선택을 분명히 구분합니다.

추천 또는 비추천을 누르는 순간 평점이 먼저 저장되며, 이유 선택 창에서 [건너뛰기]를 누르면 이유 없이 평점만 유지됩니다. 이미 선택한 같은 버튼을 다시 누르면 해당 평점은 서버 데이터베이스에서 삭제되고 버튼도 선택하지 않은 상태로 돌아갑니다. 이 과정에서 질문과 답변 원문은 피드백 데이터베이스로 보내지 않습니다.

### 공개 아카이브 문서

v1.0.2와 v1.0.3의 아카이브 날짜를 같은 Asia/Seoul 기준 날짜인 2025-10-18로 정리하고, 같은 날짜 안에서는 v1.0.3 다음에 v1.0.2가 오도록 순서를 맞췄습니다.

다섯 언어 공개 문서의 네 자리 기술 수치는 `5604`, `1015`, `5589`, `2000`처럼 천 단위 구분기호 없이 표기하도록 통일했습니다. 스페인어와 포르투갈어에서 쉼표가 소수점으로 읽힐 수 있는 혼동을 줄이기 위한 정리입니다.

이 문서 정정은 v2.2.9에 포함했습니다. 이전 버전의 계산 코드와 배포물은 변경하지 않았습니다.

## 기존 계산 결과에 영향이 있나요?

없습니다. 이번 패치는 구조요약 계산식, 입력 가능한 부호, 참조 문서 본문, AI 답변 규칙을 바꾸지 않습니다. 기존 프로토콜을 다시 계산할 필요가 없습니다.

## 테스트 및 검증

- 전체 자동 검사에서 98개 테스트 파일의 600개 검사가 통과했고, 실행 조건이 없는 7개는 건너뛰었습니다.
- 이미 정렬된 샘플 자료가 `I-X`에서 `X-I`, 다시 `I-X`로 바뀌는지 직접 확인했습니다.
- 채점 화면에서 [해석 도우미]를 선택해 시험용 로컬 세션을 시작한 뒤 해석 도우미 화면으로 이동하는지 확인했습니다. 시험용 키는 로컬 세션에서 바로 삭제했으며 OpenAI에는 전송하지 않았습니다.
- 다섯 언어의 세션 이동 경로, 일반 세션 연결 시 현재 화면 유지, 스트리밍 중 점 세 개와 유휴 상태의 아래 화살표를 자동 검사로 고정했습니다.
- 추천·비추천의 선택 표시, 이유 없는 평점 저장 요청, 같은 버튼을 다시 눌렀을 때의 삭제 요청과 서버 삭제 경로를 자동 검사로 확인했습니다.
- TypeScript 검사와 수정 파일의 정적 분석을 통과했습니다.

이번 변경은 OpenAI 답변 생성 동작을 바꾸지 않으므로 유료 API 호출 검사는 실행하지 않았습니다.

## 함께 확인한 범위

- 구조요약 계산식과 결과 항목은 변경하지 않았습니다.
- 참조 문서, 벡터 임베딩, AI 시스템 프롬프트와 플레이북은 변경하지 않았습니다.
- 채점 자료와 OpenAI API 키를 서버 데이터베이스에 저장하지 않는 기존 원칙을 유지합니다.
