# [2026-07-17] v2.2.3 버그 패치

## 먼저 확인하실 점

v2.2.3은 **구조요약 계산식과 화면 배치를 바꾸지 않은** 검색·공유 표시와 AI 응답 평가 개선 패치입니다. 기존 구조요약 결과를 다시 계산할 필요가 없고, 계산기 입력 항목이나 AI 사용 여부도 달라지지 않습니다.

검색결과와 링크 미리보기에는 다섯 언어별 제목·설명을 제공하고, 선택형 AI 응답 평가가 지나치게 크거나 빈번하게 전송되지 않도록 제한합니다.

## 검색결과와 링크 미리보기

홈 화면의 검색·공유용 제목은 다섯 언어 모두 `Yes, U Can!`로 통일했습니다. 한국어 설명은 다음 문장으로 고정했습니다.

> 회원가입, 설치, 결제가 필요 없는 Exner Rorschach 종합체계(Comprehensive System) 검사 구조요약 계산기입니다. 오픈소스이며, 본 서비스는 전문가의 임상 판단을 대체하지 않습니다.

영어·일본어·스페인어·포르투갈어에서도 같은 의미가 전달됩니다. 다섯 언어 페이지는 검색 결과와 링크 공유에서 해당 언어의 제목과 설명을 표시합니다.

공식 주소는 `https://exner.yesucan.co.kr/`이며 기존 주소도 계속 사용할 수 있습니다.

일반 검색 설명과 링크 미리보기는 같은 제목과 설명을 사용합니다. 이 변경은 페이지에 보이는 문구나 화면 배치를 바꾸지 않습니다.

검색엔진과 메신저에는 이전 정보가 일정 기간 남을 수 있고, Google은 검색어에 따라 제목이나 설명을 일부 다시 구성할 수 있습니다. 따라서 변경 내용이 모든 검색 결과와 링크 미리보기에 즉시 반영된다고 보장할 수는 없습니다.

## AI 응답 평가와 개인정보

좋아요·싫어요 평가는 계속 선택 기능입니다. 도움 여부, 선택한 이유와 서비스 집계에 필요한 정보만 기록합니다. 질문, 답변, 반응 메모, 구조요약 원문, API 키, 계정 식별자, 원본 IP 주소와 브라우저 정보는 저장하지 않습니다.

한 번의 평가는 약 2KB까지 받습니다. 1분에 10회 또는 한 번의 AI 연결에서 60회를 넘기면 잠시 기다린 뒤 다시 시도하도록 안내합니다. 이 제한을 위한 임시 기록은 최대 24시간 유지되고, 평가 정보는 최대 180일 보관합니다.
