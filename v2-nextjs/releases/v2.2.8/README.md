## 주요 수정사항

### 개요

한 반응의 [Contents]에 같은 내용 부호를 두 번 넣으면 그 부호가 두 번 집계되던 문제를 수정했습니다. 예를 들어 `Bt`를 두 칸에 반복해 넣으면 Isolation Index의 분자가 실제보다 커지고, 경계에 있는 기록에서는 CDI 판정까지 달라질 수 있었습니다. 이제 한 번 선택한 내용 부호는 같은 반응의 다른 칸에서 다시 선택할 수 없습니다. 과거 자동저장 자료에 중복 부호가 남아 있으면 원본을 임의로 바꾸지 않고 계산을 멈춘 뒤 확인할 행을 알려줍니다.

데스크톱과 모바일에서 `DV`, `DR`, `INCOM`, `FABCOM` 계열의 Level 1·Level 2 충돌을 같은 방식으로 처리합니다. 새로 선택한 부호를 남기며, 과거 저장 자료에 두 수준이 함께 있으면 Level 1을 남기고 임상가에게 확인을 요청합니다. 어느 수준이 맞는지는 원자료를 확인해 결정해야 합니다. 충돌 부호가 제거된 칸에는 빈 특수점수를 저장하지 않습니다.

이번 패치는 구조요약 계산 공식을 바꾸지 않습니다. 규칙에 맞게 입력된 기존 프로토콜은 다시 계산할 필요가 없습니다. 아래 ‘어떤 기록이 영향을 받나요?’에 적은 조건에 해당하는 자료만 원자료를 확인한 뒤 다시 계산합니다.

### 자동저장과 입력 자료

- 저장된 작업이 있는 상태에서 샘플 데이터를 열어 보아도 기존 자동저장본을 덮어쓰지 않습니다.
- 편집 직후 화면을 닫거나 다른 페이지로 이동해도 마지막 변경을 저장하도록 보완했습니다.
- 구조가 손상되었거나 지나치게 큰 자동저장 자료는 그대로 복원하지 않고 안전하게 거부합니다.
- 허용 목록에 없는 Z 부호와 카드에 맞지 않는 Z 점수는 계산 전에 차단합니다.
- CSV 파일명은 사용 중인 기기의 현지 날짜를 사용합니다. 내려받은 파일을 안전하게 열 수 있도록 보완했으며, 임상적으로 유효한 수치와 채점 부호는 원래 값으로 유지합니다.

### S-CON과 참조 문서

다섯 언어 S-CON 참조 문서에 12개 기준과 `8개 이상`의 판정 경계를 모두 명시했습니다. 계산기 화면은 지금까지와 같이 12개 기준의 충족 개수를 계산하고 8개 이상이면 체크하며, 만 15세 이상의 수검자에게 적용한다는 안내를 함께 표시합니다. 나이 입력란은 추가하지 않았고, 적용 연령의 판단은 임상가에게 남겨 둡니다.

AI 해석 도우미는 나이가 제시되지 않은 S-CON 질문에서 먼저 기준 충족 개수를 설명하고 정확한 나이를 묻습니다. 나이를 모르는 상태에서는 S-CON을 양성 또는 음성으로 확정하거나 보고서 문장으로 완성하지 않습니다.

### AI 도우미와 피드백 개인정보

- AI 연결과 대화 요청이 지나치게 반복되면 잠시 기다리도록 안내합니다.
- 이어지는 대화에서도 비공개 정보 공개 요청에는 응답하지 않고, 위기 관련 표현에는 긴급 도움 안내를 제공합니다.
- AI 답변 평가에는 대화 원문이나 IP 주소를 저장하지 않으며 최대 180일 보관합니다.

## 어떤 기록이 영향을 받나요?

다음 조건에 해당하지 않는 기존 구조요약 결과는 다시 계산할 필요가 없습니다.

1. 한 반응의 [Contents]에 같은 부호를 두 번 이상 입력한 기록
2. 데스크톱과 모바일에 Level 1·Level 2 특수점수 값이 서로 다르게 저장된 기록
3. 허용되지 않은 Z 부호나 카드에 맞지 않는 Z 점수가 외부 자료 또는 오래된 저장본에 남은 기록
4. 모바일 화면에서 `C`, `C'`, `T`, `V`, `Y`, `Cn`처럼 형태를 사용하지 않는 결정인만 입력했는데 [FQ]가 `none`이 아닌 값으로 저장된 기록

해당 기록은 원자료를 확인해 중복 또는 잘못된 부호를 바로잡은 뒤 다시 계산합니다. 앱은 임상가의 부호화 판단을 대신하지 않습니다.

## 화면, 개인정보와 계산 범위

- 새 화면이나 나이 입력란을 추가하지 않았습니다.
- [Contents]에서 이미 고른 부호가 다른 칸에서 비활성화되고, 잘못된 저장 자료에는 다섯 언어 안내가 표시됩니다.
- 구조요약 결과의 선택되지 않은 탭에도 옅은 테두리를 넣어 현재 탭과 구분하기 쉽게 했습니다. S-CON, DEPI, CDI, HVI 카드에서는 요약 체크박스와 첫 줄 문장을 수직 중앙에 맞췄습니다.
- 계산 공식과 구조요약 결과 화면의 항목은 변경하지 않았습니다.
- 자동저장된 채점 자료는 사용 중인 기기에만 남습니다. API 키는 암호화된 상태로 최대 24시간 AI 연결에 사용되며 연결을 종료하면 삭제됩니다.
- 피드백에는 정해진 이유와 집계용 정보만 기록하며 대화 원문과 원본 IP 주소는 기록하지 않습니다.

## 임상 적용 시 알아둘 점

Level 1·Level 2로 나뉘지 않는 동일 특수점수의 반복 입력과 무형태 결정인의 FQ 판단에는 기존 기준을 적용합니다. Level 1·Level 2 충돌은 데스크톱과 모바일에서 동일하게 처리합니다.

AI 도우미는 모든 임상 질문의 정확성을 보증하지 않으며, 최종 해석과 S-CON 적용 연령 판단은 임상가가 맡습니다.
