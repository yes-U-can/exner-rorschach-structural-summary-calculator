# [2026-05-21] v2.0.2 버그 패치

v2.0.2는 v2.0.1 이후 확인된 구조요약 CSV 관련 문제를 수정한 버그 패치입니다. 큰 제품 방향이나 AI 기능의 사용 방식은 바꾸지 않았고, 결과 화면에서 복사하거나 내려받는 데이터가 화면의 구조요약 계산 결과를 더 정확하게 반영하도록 정리했습니다.

**구조요약 계산값 자체는 바뀌지 않았으므로 다시 계산할 필요는 없습니다.** 다만 v2.0.1에서 복사한 구조요약 CSV로 AI 해석을 진행했다면 일부 항목이 빠지거나 같은 이름이 겹쳤을 수 있으므로, v2.0.2 이상에서 다시 복사한 값으로 해당 해석을 확인해 주세요. 내려받아 보관 중인 과거 CSV도 같은 이유로 새로 만드는 편이 안전합니다.

## 핵심 요약

- 데이터 다운로드 창의 한국어 항목명 `입력값 원자료 CSV`를 `점수계열 원자료 CSV`로 수정했습니다.
- `구조요약 값 복사하기` 버튼으로 복사되는 CSV 문자열에서 중복 헤더와 누락 항목이 생길 수 있던 문제를 수정했습니다.
- 복사와 다운로드에서 같은 구조요약 항목을 제공합니다.
- API 키로 로그인한 AI 세션에서 AI 제공자 키 오류가 발생했을 때 세션 시작 팝업이 반복해서 뜨던 문제를 수정했습니다.
- OpenAI 기본 대화 모델을 GPT-5.4에서 GPT-5.5로 업데이트했습니다.
- 해석 도우미의 구조요약 수치 붙여넣기 완료 표시를 `입력됨 ✅`으로 보강했습니다.

## 해석 도우미에서 확인할 점

v2.0.1의 해석 도우미는 결과 화면에서 `구조요약 값 복사하기` 버튼으로 복사한 값을 해석 AI 화면의 구조요약 수치 입력란에 붙여넣고 대화를 시작하는 방식입니다.

v2.0.1에서는 `D`, `Zf`, `Zd`, `GHR`, `PHR`처럼 여러 구역에서 쓰이는 이름이 복사한 자료에서 중복될 수 있었습니다. `Single`, `Contents`, `Form Quality`, `Special Scores`, `Approach`, `Blends`처럼 화면에 보이는 일부 항목이 빠질 수도 있었습니다.

API 키 연결이나 AI 대화 기능 자체의 문제는 아니었지만, 해석 도우미에 전달되는 구조요약 자료가 불완전하거나 모호할 수 있었습니다.

## 달라진 점

이제 복사와 다운로드에서 빠짐없이 같은 항목을 제공하며, 이름이 겹치는 항목도 서로 구분해 보여 줍니다.

점수계열 원자료 CSV에는 계산에 실제로 사용된 채점 행만 포함됩니다. 카드가 비어 있는 임시 행이나 미완성 행은 제외됩니다.

해석 도우미는 결과 화면에서 복사한 구조요약 자료를 받아들이며, 관련 없는 일반 문장은 구조요약 자료로 사용하지 않습니다.
