# [2026-09-01] v2.2.12 버그 패치

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

## 이번 릴리즈

v2.2.12에서는 쿠키 없는 익명·집계 방문 통계를 위해 Vercel Web Analytics를 사용하기 시작했습니다. 채점 화면을 새로고침할 때 표가 순간적으로 옮겨 보이던 현상을 고치고, 시작 선택창 상단에는 서울임상심리연구소 CI와 연구소 홈페이지 연결을 추가했습니다.

계산식, 채점 기준과 산출값은 바뀌지 않았습니다. 기존 프로토콜을 다시 계산할 필요가 없습니다.

## 무엇이 달라졌나요?

Vercel Web Analytics를 통해 방문한 페이지, 접속 경로, 대략적인 국가·지역, 브라우저·운영체제·기기 유형 같은 방문 현황을 익명·집계 형태로 확인합니다.

Vercel Web Analytics는 방문자를 식별하는 쿠키를 사용하지 않으며, 서로 다른 날짜나 웹사이트의 이용 기록을 연결하지 않습니다.

채점 화면을 새로고침하면 표가 초기 위치에 나타났다가 최종 위치로 옮겨 보이던 현상을 수정했습니다. 이제 표의 위치가 정해진 뒤 한 번만 표시됩니다.

채점 화면에 들어갈 때 나타나는 시작 선택창 상단에 서울임상심리연구소 CI와 한글·영문 명칭을 표시합니다. CI와 명칭을 누르면 연구소 홈페이지가 새 탭에서 열립니다.

## 누가 영향을 받나요?

웹앱을 방문하는 모든 사용자가 적용 대상입니다. 특히 데스크톱에서 채점 화면을 새로고침할 때 표가 안정된 위치에 표시됩니다. 계산 기능과 AI 도우미의 사용 방법은 그대로입니다.

## 기존 결과를 다시 계산해야 하나요?

아니요. 계산식, 채점 기준과 산출값은 변경하지 않았으므로 기존 프로토콜을 다시 계산할 필요가 없습니다.

## 개인정보와 임상적 한계

구조요약 입력값, 계산 결과, AI 대화 내용과 API 키는 방문 통계에 포함되지 않습니다. 방문 통계와 화면 표시만 달라졌으며, 계산이나 임상적 판단에는 영향을 주지 않습니다.

본 서비스는 전문가의 임상 판단을 대체하지 않습니다.
