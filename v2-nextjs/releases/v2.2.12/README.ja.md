# [2026-09-01] v2.2.12 バグ修正

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

## 今回のリリース

v2.2.12では、訪問統計をCookieを使用しない匿名・集計方式に変更しました。構造一覧表の入力値、計算結果、AIチャットの内容、APIキーは訪問統計に含まれません。

計算式と出力値は変更していません。既存のプロトコルを再計算する必要はありません。

## 何が変わりましたか？

新しい訪問記録にはGoogle Analyticsを使用しません。今後はVercel Web Analyticsを使用し、閲覧したページ、流入元、おおよその国・地域、ブラウザ、オペレーティングシステム、端末の種類などを匿名・集計形式で確認します。

Vercel Web Analyticsは訪問者を識別するCookieを使用せず、異なる日付やウェブサイト間の利用記録を関連付けません。

## 誰が影響を受けますか？

ウェブアプリを訪問するすべての利用者が対象です。個別の設定や同意画面で選択する項目はありません。計算画面とAIアシスタントの利用方法は従来どおりです。

## 既存の結果を再計算する必要がありますか？

いいえ。計算式、コーディング基準、出力値は変更していないため、既存のプロトコルを再計算する必要はありません。

## プライバシーと臨床上の限界

構造一覧表の入力値、計算結果、AIチャットの内容、APIキーは訪問統計に含まれません。今回の変更は一般的な訪問状況の確認方法だけに適用され、計算や臨床判断には影響しません。

本サービスは専門家の臨床判断に代わるものではありません。
