# [2026-09-01] v2.2.12 バグ修正

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

## 今回のリリース

v2.2.12では、Cookieを使用しない匿名・集計形式の訪問統計のためにVercel Web Analyticsの利用を開始しました。また、採点画面を再読み込みしたときに表が一瞬移動して見える現象を修正し、開始選択画面の上部にソウル臨床心理研究所のシンボル、韓国語・英語名称、研究所ウェブサイトへのリンクを追加しました。

計算式、コーディング基準、出力値は変更していません。既存のプロトコルを再計算する必要はありません。

## 何が変わりましたか？

Vercel Web Analyticsを使用し、閲覧したページ、流入元、おおよその国・地域、ブラウザ、オペレーティングシステム、端末の種類などを匿名・集計形式で確認します。

Vercel Web Analyticsは訪問者を識別するCookieを使用せず、異なる日付やウェブサイト間の利用記録を関連付けません。

採点画面の再読み込み時に、表が仮の位置に表示された後で最終位置へ移動して見える現象を修正しました。現在は最終位置が決まってから一度だけ表示されます。

開始選択画面の上部に、ソウル臨床心理研究所のシンボルと韓国語・英語名称を表示します。この表示を選択すると、研究所ウェブサイトが新しいタブで開きます。

## 誰が影響を受けますか？

ウェブアプリを訪問するすべての利用者が対象です。特にデスクトップでは、採点画面を再読み込みしたときも表が安定した位置に表示されます。計算機能とAIアシスタントの利用方法は従来どおりです。

## 既存の結果を再計算する必要がありますか？

いいえ。計算式、コーディング基準、出力値は変更していないため、既存のプロトコルを再計算する必要はありません。

## プライバシーと臨床上の限界

構造一覧表の入力値、計算結果、AIチャットの内容、APIキーは訪問統計に含まれません。変更されたのは訪問統計と画面表示のみで、計算や臨床判断には影響しません。

本サービスは専門家の臨床判断に代わるものではありません。
