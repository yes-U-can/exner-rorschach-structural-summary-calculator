## 주요 수정사항

### 개요

이번 버그 패치에서는 구조요약 계산 결과를 그대로 두고, Lower Section에서 빠져 있던 `GHR:PHR` 표시와 PDF 출력 형식을 보완했습니다. 동시에 검토 대상 자료 전체를 53개 문헌군으로 정리해 본문과 목차를 전수감사하고, Exner 종합체계의 직접 근거·해석 보조 자료·다른 로샤 체계·역사 자료·제품 범위 밖 자료를 구분했습니다.

전수감사 결과, 현재 구조요약 계산값을 바꿔야 할 새로운 오류는 발견되지 않았습니다. 규칙에 맞게 입력한 기존 프로토콜은 다시 계산할 필요가 없습니다.

다른 체계의 원문은 생산 RAG 코퍼스에 섞지 않았습니다. AI 도우미에는 R-PAS, Basic Rorschach, 프랑스 투사법, 지역 체계, MMPI 통합, 진단·치료·법적 판단과 프롬프트 탈취 시도를 Exner 종합체계 질문과 구분하는 경계를 보강했습니다. 새 화면, 나이 입력란과 개인정보 수집 항목은 추가하지 않았습니다.

### 세부사항

#### Lower Section의 GHR:PHR 표시

앱은 각 반응의 GHR와 PHR을 이미 판정하고 Upper Section에 각각의 합계를 표시하고 있었습니다. 그러나 결과 화면과 PDF의 Lower Section Interpersonal 영역에는 원래 구조요약 양식에 있는 `GHR:PHR` 비율이 빠져 있었습니다.

이제 `GHR:PHR`를 `COP`, `AG` 다음, `a:p` 앞에 표시합니다. GHR/PHR 판정 순서와 합계는 바꾸지 않았으므로 기존 계산 결과는 달라지지 않습니다.

#### PDF 출력 정리

PDF의 일반 Lower Section 카드에는 실제 값과 관계없는 세 번째 빈 칸이 있었습니다. Core와 Ideation처럼 별도 구조가 필요한 카드는 그대로 두고, Affect, Interpersonal, Self-Perception, Mediation, Processing 카드는 항목명과 값으로 이루어진 두 칸 표로 정리했습니다.

S-CON, DEPI, CDI, HVI, OBS 카드에는 각 지표의 최종 판정 체크박스를 인쇄합니다. 최종 판정과 세부 기준 사이, OBS의 세 가지 조합 기준과 별도 결합 기준 사이에도 구분선을 넣었습니다. HVI의 긴 판정 문장은 한 글자만 다음 줄로 밀리지 않도록 인쇄 크기를 조정했습니다.

이 변경은 PDF의 읽기 편의와 구조요약 항목의 완전성을 보완한 것입니다. 계산식과 판정값은 바뀌지 않습니다.

이번에는 계산 규칙을 확인한 문헌과 쪽수를 공개 기록에 함께 남깁니다.

1. Exner, J. E., Jr. (2003). *The Rorschach: A Comprehensive System, Volume 1: Basic Foundations and Principles of Interpretation* (4th ed.). John Wiley & Sons.
2. Exner, J. E., Jr. (2001). *A Rorschach Workbook for the Comprehensive System* (5th ed.). Rorschach Workshops.

자세한 항목별 대응은 [구조요약 원전 교차검증 기록](../../source/docs/ops/2026-08-04-v2.2.10-calculation-source-crosscheck.md)에 정리했습니다.

### PTI의 판본 차이

Volume 1 제4판 156쪽은 PTI 네 번째 조건의 고-R 분기를 `R > 16`이면서 `WSum6 > 16`으로 인쇄합니다. Workbook 제5판 101쪽과 RIAP 5의 운영 출력은 `R > 16`이면서 `WSum6 > 17`을 사용합니다.

앱은 후대 Workbook과 운영 출력에 맞춰 `> 17`을 유지합니다. `R=17, WSum6=17`에서는 해당 조건이 성립하지 않고 `R=17, WSum6=18`에서 성립하는 사례를 자동 검사로 고정했습니다. 두 판본의 차이도 검증 기록에 그대로 남겼습니다.

### S-CON과 나이

S-CON은 만 15세 이상에 적용합니다. 앱은 피검자의 나이를 수집하지 않으며 나이 입력란도 추가하지 않았습니다. 입력된 구조요약 값에 따른 조건 충족 여부를 계산해 보여 주고, 실제 적용 여부는 나이와 전체 임상 자료를 알고 있는 임상가가 판단합니다.

## 53개 문헌군을 어떻게 확인했나요?

확보한 원본 PDF 51개와 프로젝트 내부 파생 자료를 같은 제목·판본·내용을 기준으로 묶어 53개 문헌군으로 정리했습니다. 물리적 파일 수가 아니라 같은 문헌의 중복본과 번역·파생 관계를 구분한 문헌군 수입니다.

| 분류 | 문헌군 수 | 제품에서의 역할 |
| --- | --- | --- |
| Exner CS 직접 원전 | 7 | 계산·부호화의 직접 근거 또는 판본 대조 |
| 핵심 해석 자료 | 2 | 검증된 Exner 해석 원칙의 교차 확인 |
| 전문 보충 자료 | 8 | 특정 주제의 한계와 맥락 확인 |
| R-PAS·기타 체계 경계 자료 | 10 | 다른 체계가 섞이지 않게 차이를 확인 |
| 역사·연구 맥락 자료 | 16 | 계산 근거가 아닌 역사·연구 맥락 |
| 프로젝트 내부 파생 자료 | 3 | 오류와 구현 계보 추적, 정답 근거에서 제외 |
| 비전문·제품 범위 밖 자료 | 7 | 본문 확인 후 제품 근거에서 제외 |

모든 문헌군의 서지정보를 확인했습니다. 정식 목차가 있는 자료는 전체 목차를, 목차가 없는 자료는 전체 장 제목 흐름을 확인한 뒤 제품과 관련된 장과 쪽수를 읽었습니다. OCR은 검색과 위치 찾기에 사용했으며, 수식·표·체크박스·위첨자·아포스트로피·비율은 원본 페이지를 다시 대조했습니다. 중국어 자료 3개는 필요한 장을 별도로 재판독했습니다.

제외 자료도 제목만 보고 치우지 않았습니다. 본문을 확인해 왜 계산·해석 근거가 될 수 없는지 기록했습니다. Excel, Perl, v1 GAS와 프로젝트 내부 메모는 구현 계보를 추적하는 자료로만 사용하고 계산 정답의 근거에서는 제외했습니다.

53개 문헌군의 서지정보, 분류, 제품에서의 역할, Exner 계산 근거와 다른 체계의 경계는 [문헌 전수감사와 체계 경계 기록](../../methodology/reference-audit-v2.2.10/)에 공개했습니다.

## 참조 문서와 AI 도우미

Lower Section의 표시를 바로잡으면서 다섯 언어 Interpersonal 참조 문서에도 `GHR:PHR`를 추가했습니다. 어느 한쪽이 많다는 사실은 대인관계 표상의 한 양상을 보여 줄 수 있지만, 이 비율만으로 전반적인 대인관계 기능을 결론 내릴 수 없다는 한계도 함께 명시했습니다.

생산 RAG 코퍼스에는 쪽수 단위로 검증한 Exner 종합체계 내용만 남겼습니다. R-PAS, Basic Rorschach, 프랑스 투사법의 kan/kob/clob, 중국어권 지역 체계와 역사적 체계의 원문은 벡터 공간에 넣지 않았습니다. 다른 체계에서 확인한 차이는 짧은 경계 규칙과 평가 질문으로만 반영했습니다.

AI 도우미는 R-PAS 변환·해석, Exner와 다른 체계의 혼합, MMPI 통합, 진단·치료·법적 판단, 무관한 질문, 시스템 프롬프트·API 키·원문 탈취 시도와 피검자 정보로 위장한 프롬프트 인젝션을 거절하고 Exner 종합체계 질문으로 범위를 되돌립니다. 정상적인 Exner 질문은 과잉 차단하지 않는지도 함께 검사합니다.

다섯 언어 참조 문서 203개씩을 다시 묶고 OpenAI `text-embedding-3-large` 검색 벡터 5604개를 확인했습니다. 오래된 벡터와 본문 해시 불일치는 모두 0개였습니다.

GPT-5.5에는 다섯 언어로 같은 GHR:PHR 경계 질문을 각각 한 번씩 물었습니다. 검사 5회는 모두 끝까지 완료됐고, 다섯 질문 모두 Lower Section Interpersonal 문서를 첫 번째 검색 근거로 사용했습니다. 측정된 API 비용은 USD 0.154025였습니다. API 키와 답변 원문은 공개 기록에 저장하지 않았습니다.

## 기존 계산 결과에 영향이 있나요?

없습니다. 기존 프로토콜을 다시 계산할 필요는 없습니다.

- GHR와 PHR의 판정과 합계는 이전 버전에서도 계산됐습니다.
- 이번 패치는 Lower Section의 누락된 비율 표시와 PDF 표현을 보완합니다.
- PTI를 포함한 계산식은 원전 교차검증 뒤 현재 값을 유지했습니다.

이전 버전에서 만든 PDF를 새 형식으로 보관하려면 같은 프로토콜을 다시 열어 PDF만 다시 만들면 됩니다.

## 테스트 및 검증

- 53개 문헌군 모두 최종 본문감사 판정을 받았고, 미감사 문헌군과 미배정 파일은 0개였습니다.
- 자동 검색 결과를 최종 근거로 쓰지 않고 162개 본문 구간과 서로 다른 원본 386쪽을 문헌군별로 다시 지정했습니다.
- 앱이 표시하는 Upper Section, Lower Section, Special Indices와 입력 규칙을 31개 근거 항목으로 나누어 원전 쪽수·계산 함수·화면·PDF·검사 사례에 연결했습니다.
- 계산 근거 항목이 가리키는 원본을 역검증하여 Workbook 제5판 PDF 53쪽과 Volume 1 제4판 PDF 62쪽이 실제 검토 기록에 포함되는지 자동으로 확인했습니다. 이 과정에서 운동 첨자, 결정인 중복, 내용 중복 규칙의 잘못된 인쇄 쪽수 표기를 바로잡았으며 계산식과 계산값은 바뀌지 않았습니다.
- 31개 중 28개는 직접 일치를 확인했고, 1개는 PTI 판본 차이, 1개는 동일 비수준 Special Score 반복 입력의 미해결 근거, 1개는 제품 범위 밖으로 명시했습니다. 불확실한 항목은 추측으로 수정하지 않았습니다.
- 공개 RIAP 구조요약 사례 3건과 Workbook 제5판 사례를 다시 계산했습니다.
- 고정된 가상 프로토콜 2000개를 별도로 작성한 계산식과 비교했습니다.
- 여섯 Special Indices의 각 조건 바로 아래와 바로 위 경계를 확인했습니다.
- 다섯 언어에서 같은 입력은 같은 계산 결과를 냈습니다.
- 다른 체계와의 경계를 15개 항목으로 정리하고, AI 도우미용 단일 대화 110개와 여러 차례 이어지는 대화 10개의 다섯 언어 사례를 고정했습니다.
- 전체 자동 검사에서 102개 테스트 파일의 626개 검사가 통과했고, 실행 조건이 없는 7개는 건너뛰었습니다.
- 보안 공지가 적용된 `fast-uri`, `js-yaml`, `nanoid` 수정 버전으로 전이 의존성을 고정했으며, 운영·개발 의존성 감사와 비밀정보 검사를 모두 통과했습니다.
- Lower Section 화면과 PDF에서 `GHR:PHR`가 `a:p` 위에 있는지 확인했습니다.
- PDF Special Indices의 최종 체크박스, 구분선과 HVI 줄바꿈을 확인했습니다.
- TypeScript, 다섯 언어 문구 검사, 정적 분석과 222개 배포 페이지 생성을 통과했습니다.
- 다섯 언어 참조 문서 203개씩과 검색 벡터 5604개를 대조했으며, 누락·오래된 행·본문 해시 불일치는 모두 0개였습니다.
- GPT-5.5의 다섯 언어 GHR:PHR 경계 질문은 5회 모두 완료됐습니다.

## 공개 범위와 저작권 경계

이번 패치노트와 공개 방법론 문서에는 53개 문헌군의 문헌명, 판, 출판 정보, 자료의 역할, 계산 근거의 인쇄 쪽수, 확인한 규칙과 반복 검사 결과를 공개합니다.

개별 원본 파일, OCR 원문, 로컬 파일명, 비공개 작업 식별자, 프로젝트 내부 파생 자료의 사적인 제목은 공개하지 않습니다. 원전은 필요한 규칙만 요약하며 긴 원문 문장을 복제하지 않습니다. API 키, GPT-5.5 답변 원문과 실제 검사 자료도 공개 저장소에 넣지 않습니다.
