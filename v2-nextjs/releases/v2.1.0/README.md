# [2026-06-22] v2.1.0 마이너 패치

v2.1.0은 지원 브라우저에서 웹앱을 설치형 앱처럼 열 수 있게 하고, 공개 프로젝트 RorScore를 크레딧에 명시하며, AI가 코딩 질문에 알맞은 참조 문서를 먼저 찾도록 개선한 패치입니다.

## 핵심 요약

- Chrome·Edge 등 지원 브라우저에서 웹앱을 설치형 앱처럼 열 수 있습니다.
- 설치 기능에는 오프라인 저장, 푸시 알림과 백그라운드 동기화가 없으며, 민감한 평가 데이터나 AI 응답을 기기에 별도로 저장하지 않습니다.
- `DQ+` 같은 코딩 질문을 하면 AI가 관련 채점 입력 문서를 먼저 참고합니다.
- 공개 프로젝트 RorScore를 참고 자료로 크레딧에 명시했습니다.

## 설치와 자료 보관

설치 기능은 앱의 자료 보관 방식이나 API 키 보호 원칙을 바꾸지 않습니다. API 키는 암호화된 상태로 AI 연결에 사용되며, 연결은 최대 24시간 동안만 유지되고 종료하면 키도 삭제됩니다.

설치한 앱도 인터넷에 연결해 사용하며, 민감한 평가 자료나 AI 응답을 오프라인에 저장하지 않습니다.

이 변경은 계산 결과에 영향을 주지 않습니다. 코딩 도우미가 "DQ+는 언제 DQo나 DQv/+가 아니라 DQ+로 코딩해야 하나?" 같은 질문을 받으면 해석 문서보다 관련 채점 입력 문서를 먼저 참고합니다.

## RorScore 기여 표기

공개 프로젝트 RorScore를 참고 자료로 크레딧에 명시했습니다.
