# [2026-04-27] v2.0.1 버그 패치

v2.0.1은 v2.0.0 공개 이후 발견된 이용상의 문제를 수정한 패치입니다. 구조요약 계산, 참조 문서, BYOK 기반 코딩 도우미와 해석 도우미라는 제품 범위는 그대로 유지됩니다.

## 핵심 요약

- 해석 도우미의 입력 흐름을 파일 첨부 중심에서 구조요약 수치 입력 중심으로 정리했습니다.
- 코딩 도우미와 해석 도우미에서 AI가 너무 길게 말하거나, 사용자가 제어하기 어려운 방식으로 화면을 움직이던 문제를 줄였습니다.
- AI 자동 채우기 흐름을 제거했습니다. 부호화와 해석은 사용자가 AI와 대화하며 검토하는 방식만 남겼습니다.
- API 키 연결·종료 화면이 겹치거나 필요한 안내가 나타나지 않던 문제를 수정했습니다.
- 다크모드에서 토스트와 시스템 안내 말풍선이 투명하게 보이거나 읽기 어려웠던 문제를 수정했습니다.
- 참조 문서의 `+`, `-`, `v/+` 같은 부호를 눌렀을 때 페이지가 열리지 않던 문제를 수정했습니다.
- 서비스 소개, 이용약관과 개인정보처리방침을 현재 기능에 맞게 수정했습니다.

## 해석 도우미에 구조요약 자료 입력

v2.0.0에서는 해석 도우미가 구조요약 CSV 파일을 첨부하는 흐름으로 설명되어 있었습니다. 파일 첨부 방식은 사용자가 어떤 파일을 넣어야 하는지 헷갈릴 수 있고, AI가 파일 내용을 안정적으로 같은 방식으로 읽지 못할 여지가 있었습니다.

v2.0.1에서는 결과 화면에서 복사한 구조요약 수치를 해석 도우미의 별도 입력란에 붙여넣도록 흐름을 정리했습니다. 결과 화면의 구조요약 값을 복사한 뒤, 해석 도우미 입력창 왼쪽의 작은 구조요약 수치 입력란에 붙여넣고 질문을 시작할 수 있습니다.

구조요약 수치를 붙여넣으면 원문 전체 대신 `입력됨`으로 표시됩니다. 같은 브라우저 창을 사용하는 동안에는 사용자가 직접 지우거나 새 값으로 바꾸기 전까지 입력 내용이 유지됩니다.

또한 해석 도우미가 아무 자료나 받지 않도록, 결과 화면에서 복사한 구조요약 값 형식에 맞는 입력만 사용하도록 제한했습니다. 사용자가 엉뚱한 텍스트를 넣고 대화를 시작하려 하면, 결과 화면의 구조요약 값 복사 기능을 사용하라는 안내를 띄우도록 했습니다.

## 해석 도우미 답변

해석 도우미의 답변은 사용자가 이어서 대화할 수 있는 길이와 형식으로 조정했습니다. v2.0.0 직후에는 답변이 지나치게 길어지거나, 중간에서 끊기거나, 수치를 한 줄에 너무 많이 나열해 읽기 어려운 경우가 있었습니다.

해석 도우미는 한 번의 답변에서 너무 많은 주제를 한꺼번에 펼치지 않고, `근거 수치`와 `해석 가설`을 나누어 보여 줍니다.

해석 도우미는 `프로토콜` 대신 `검사자료`, `응답자료`, `구조요약 자료`처럼 더 직관적인 표현을 사용합니다.

## 코딩 도우미

코딩 도우미는 채점 화면에서 사용자가 반응을 부호화할 때 대화로 도움을 받는 기능입니다. v2.0.1에서는 코딩 도우미가 자동으로 행을 채우거나 버튼으로 필드를 적용하는 흐름을 제거했습니다.

이제 코딩 도우미는 사용자가 선택한 행과 전체 시트 맥락을 바탕으로 후보와 근거를 대화로 설명하는 역할만 합니다. 사용자는 AI의 설명을 참고하되, 실제 부호화 값은 직접 검토하고 입력해야 합니다.

채점 화면에서 `Ctrl/Cmd+J`로 코딩 도우미를 열 수 있는 흐름은 유지했습니다. 아무 행도 선택하지 않은 상태에서는 특정 중심 행 없이 전체 시트만 맥락으로 사용하고, 선택된 행이 있으면 그 행을 더 중요한 맥락으로 다룹니다.

## AI 자동 채우기 제거

`AI 자동 채우기` 기능을 제거했습니다. 이 기능은 반응 메모와 카드 정보를 바탕으로 현재 행의 부호화 필드를 한 번에 채우도록 시도하는 흐름이었습니다.

로샤 부호화는 임상가의 검토와 판단이 필요한 작업입니다. AI의 제안을 충분히 검토하지 않고 받아들이는 일을 막기 위해 자동 채우기 기능을 제거했으며, 최종 입력은 임상가가 결정합니다.

그 결과 v2.0.1의 AI 기능은 더 단순해졌습니다. 웹앱 안의 AI는 코딩 도우미와 해석 도우미, 이 두 가지 대화형 보조 기능만 제공합니다.

## API 키 연결 화면

API 키는 AI 연결이 유지되는 동안만 사용되며 연결을 종료하면 삭제됩니다.

OpenAI 입력란에 Google API 키를 넣거나 Google 입력란에 OpenAI API 키를 넣으면 올바른 입력란을 안내합니다.

API 연결 종료 버튼과 키 입력 창이 서로 겹치던 문제도 수정했습니다. API 키를 연결하지 않은 상태에서 해석 도우미를 열면 필요한 절차를 안내합니다.

## AI 모델 선택

사용자는 모델을 직접 고르지 않습니다. 웹앱은 출시된 지 최소 한 달 이상 지나 안정성이 확인된 모델 중에서 서비스가 정한 최신 모델을 자동으로 사용합니다.

모델 선택 안내는 필요한 화면에만 표시해 사용자가 직접 모델을 골라야 하는 것처럼 보이지 않게 했습니다.

## 다크모드 안내

다크모드에서 시스템 안내 말풍선이나 우측 상단 토스트가 투명하게 보이거나, 배경과 섞여 잘 읽히지 않는 문제가 있었습니다. v2.0.1에서는 토스트와 채팅 안내 메시지의 배경색, 테두리와 글자색을 더 분명하게 표시합니다.

성공·경고·시스템 안내가 다른 화면 요소에 가려지거나 배경과 섞이지 않도록 조정했습니다.

## AI 대화 화면

코딩 도우미와 해석 도우미 모두에서 불필요한 안내 문구와 중복 메시지를 줄였습니다. AI 모델명, 참조 문서 목록, 필드 적용 버튼처럼 사용자의 대화 흐름을 방해하거나 과한 기능처럼 보이는 요소를 제거했습니다.

AI가 답변하는 동안 화면이 강제로 계속 아래로 내려가 사용자가 스크롤을 제어하기 어려웠던 문제도 줄였습니다. 이제 사용자가 이전 내용을 보고 있는 상황에서는 자동 스크롤이 과하게 개입하지 않도록 정리했습니다.

답변을 기다리는 동안 보이는 말풍선의 점 움직임도 눈에 덜 거슬리도록 완화했습니다. 대화형 도구는 사용자가 오래 바라보는 화면이므로, 작은 움직임이라도 피로감을 줄 수 있다는 점을 반영했습니다.

## 열리지 않던 참조 문서

참조 문서에는 `+`, `-`, `v/+`처럼 부호 자체가 문서 이름에 포함되는 항목이 있습니다. v2.0.0에서는 이 부호가 포함된 일부 링크가 열리지 않았습니다.

이제 `[부호화/발달질] v`, `[부호화/발달질] v/+`, `[부호화/형태질] +`, `[부호화/형태질] -` 같은 항목을 눌러도 올바른 문서가 열립니다.

## 서비스 안내

서비스 소개, 이용약관과 개인정보처리방침을 실제 제공 기능에 맞게 수정했습니다. 앱에서 별도의 AI 크레딧·결제·스토어를 제공하는 것처럼 보이던 잘못된 안내도 바로잡았습니다.
