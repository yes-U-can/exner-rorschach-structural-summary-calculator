# [2026-07-12] v2.1.9 버그 패치

## 먼저 확인하실 점

v2.1.9는 코딩 도우미와 해석 도우미가 답변 전에 질문에 맞는 참조 문서를 더 안정적으로 찾도록 검색 방식을 개선한 패치입니다.

앱 화면은 변경하지 않았습니다. 다섯 언어에서 질문과 관련된 참조 문서를 더 정확히 찾고, 코딩 도우미가 사용자가 선택한 행만 참고하도록 개선했습니다.

## 핵심 요약

- 한 글자 자연어가 로샤 코드로 오인되던 문제를 줄이면서 `Card I`, `Content A`, 소문자 결정인 `m`처럼 문맥상 명시된 코드는 보존했습니다.
- 한국어 조사·어미와 일본어가 포함된 질문, `3r+(2)/R` 같은 복합 지표를 더 정확히 인식합니다.
- 질문과 관련된 문서를 더 정확히 찾습니다.
- 의미가 너무 약한 결과를 제외하고 같은 참조 문서가 여러 번 나타나지 않도록 했습니다.
- 코딩 도우미는 현재 선택한 행과 사용자가 함께 선택한 행만 참고합니다.

이번 패치는 참조 문서 검색을 개선하지만 AI가 최종 부호를 자동 확정하거나 진단을 내리지는 않습니다. 최종 판단은 임상가가 맡습니다.

## 남아 있는 한계

- 검색 개선은 임상적 정확성을 증명하지 않습니다.
- GPT-5.5 응답에는 확률성이 있으므로 모든 미래 응답을 보장하지 않습니다.
- 실제 임상 유용성, 다국어 문장 품질과 안전성은 자격을 갖춘 전문가가 판단해야 합니다.
