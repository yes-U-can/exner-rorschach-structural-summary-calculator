# [2026-07-13] v2.1.10 버그 패치

## 먼저 확인하실 점

v2.1.10은 v2.1.9 이후에도 남아 있던 참조 문서 검색 문제를 수정한 패치입니다.

앱 화면과 계산식은 변경하지 않았습니다. 일본어 문장에 붙은 로샤 부호를 보존하고, 넓은 해석 질문에는 해석 문서만 사용하도록 했습니다. AI는 최종 부호를 확정하거나 임상가의 판단을 대신하지 않습니다.

## 핵심 요약

- `FQ+の...`, `v/+の...`, `3r+(2)/Rの...`처럼 로샤 부호 뒤에 일본어가 이어져도 전체 부호로 인식합니다.
- 자연스러운 전체 해석 질문에도 관련 해석 문서를 제시하고, 넓은 질문에는 해석 문서만 제시합니다.
- 같은 참조 문서가 검색 결과에 중복으로 나타나지 않도록 개선했습니다.

AI는 부호를 자동 확정하거나 진단을 내리지 않으며, 최종 판단은 임상가가 맡습니다.

## 남아 있는 한계

- 질문의 표현에 따라 관련 해석 문서를 놓칠 수 있습니다.
- 검색과 답변 방식의 개선은 임상적 정확성을 증명하지 않습니다.
- 실제 임상 유용성, 다국어 문장 품질과 안전성은 자격을 갖춘 전문가가 판단해야 합니다.
