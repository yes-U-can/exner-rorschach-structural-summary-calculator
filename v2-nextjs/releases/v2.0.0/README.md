# [2026-02-15] v2.0.0 메이저 패치

v2.0.0은 v1.4.1을 새로운 웹앱으로 옮긴 첫 번째 버전 2 릴리즈입니다. v1의 핵심이었던 로샤 Exner(CS) 체계 구조요약 계산 흐름은 유지하면서 다국어 화면, 참조 문서 검색, BYOK 방식의 AI 보조 기능을 추가했습니다.

이번 버전의 가장 큰 변화는 사용자가 본인의 OpenAI 또는 Google API 키를 연결해 AI 기능을 쓰는 BYOK(Bring Your Own Key) 방식입니다. AI 사용 비용은 연결한 계정에서 발생하며, API 키는 AI 연결이 유지되는 동안만 사용됩니다.

## v1.4.1에서 유지한 것

v1.4.1의 핵심 목적은 그대로 유지했습니다. 사용자는 로샤 반응을 행 단위로 입력하고, 카드, 반응 위치, 발달질, 결정인, 형태질, 반응 내용, 특수점수 등 구조요약 계산에 필요한 값을 정리한 뒤 결과를 계산할 수 있습니다.

v1에서 제공하던 구조요약 계산 흐름, 결과 확인, CSV 내보내기와 다국어 지원도 v2에서 이어받았습니다. 입력 화면과 결과 화면은 모바일과 데스크톱에서 사용하기 쉬운 웹앱 화면으로 다시 구성했습니다.

## 이용 방식

주요 화면은 채점 화면, 해석 도우미, 참조 문서, 계정 관리, 버전 아카이브로 나뉩니다. 사용자는 로그인하지 않아도 기본 계산 기능과 참조 문서 검색을 사용할 수 있고, AI 기능을 쓰려면 로그인 후 API 키를 연결해야 합니다.

## BYOK AI 연결

v2의 AI 기능은 BYOK 전용으로 동작합니다. 앱에서 별도의 AI 크레딧이나 구독을 판매하지 않으며, 사용자는 OpenAI 또는 Google 중 하나의 API 키를 연결할 수 있습니다.

API 키는 AI 연결이 유지되는 동안만 사용되며, 로그아웃하거나 연결이 만료되면 삭제됩니다. OpenAI 키와 Google 키를 잘못된 입력란에 넣으면 바로 안내합니다.

모델은 사용자가 직접 고르지 않습니다. 웹앱은 출시 후 일정 기간이 지나 안정성이 확인된 모델 중에서 서비스가 정한 최신 모델을 자동으로 사용합니다. v2.0.0 기준 OpenAI는 GPT-5.4, Google은 Gemini 2.5 Pro를 기본 모델로 둡니다.

AI 제공자가 요청을 거절하는 경우에도 오류를 하나로 뭉개지 않도록 정리했습니다. API 키가 잘못된 경우, 결제 또는 사용량 한도 문제가 있는 경우, 해당 API 키로 선택된 모델을 사용할 수 없는 경우를 구분해 사용자에게 안내합니다.

## 코딩 도우미

채점 화면의 AI는 코딩 도우미로 정리했습니다. 여기서 말하는 코딩은 프로그래밍이 아니라, 로샤 반응을 Exner(CS) 체계의 기호와 범주로 부호화하는 과정을 뜻합니다.

코딩 도우미는 Ctrl/Cmd+J 단축키로 열 수 있습니다. 사용자가 현재 채점 화면에 입력한 전체 시트가 기본 맥락으로 전달되며, 사용자가 특정 행을 선택한 경우에는 그 행이 더 중요한 맥락으로 강조됩니다. 아무 행도 선택하지 않은 상태에서는 특정 중심 행 없이 전체 시트 맥락만 사용합니다.

코딩 도우미는 답을 자동으로 확정하지 않습니다. 반응의 위치, 결정인, 형태질, 내용 범주 등을 검토할 때 참조 문서와 입력 내용을 바탕으로 가능한 후보와 근거를 설명합니다.

v2.0.0은 자동 채우기 버튼을 제공하지 않습니다. AI는 후보와 근거를 설명할 뿐이며, 최종 부호화는 임상가가 반응 맥락을 검토해 결정합니다.

## 해석 도우미

해석 도우미는 구조요약 수치 CSV를 바탕으로 해석 대화를 이어가기 위한 AI 화면입니다. 사용자는 구조요약 수치가 담긴 CSV 파일을 첨부하고, 연령, 성별, 관찰 맥락, 임상가가 이미 생각한 가설이나 질문을 함께 적어 AI에게 검토를 요청할 수 있습니다.

해석 도우미는 구조요약 결과의 패턴을 설명하고, 사용자가 세운 가설을 점검하는 보조 역할을 합니다. 공식 진단이나 최종 해석을 대신하지 않으며, 최종 판단은 임상가가 맡습니다.

## 참조 문서

v2는 웹앱과 AI 도우미가 참고하는 짧은 설명 문서 모음을 함께 제공합니다. 이 문서들은 구조요약 계산, 부호화, 해석 과정의 주요 개념을 설명하며 참조 문서 화면에서 직접 검색할 수 있습니다.

참조 문서는 서울임상심리연구소와 모오가 함께 제작하고 정리한 자료를 바탕으로 구성했습니다. AI가 어떤 지식을 근거로 답변하는지 사용자가 확인할 수 있도록 공개하는 것이 목표입니다. 이는 AI 기능을 블랙박스로 두지 않고, 사용자가 근거를 확인하며 판단할 수 있게 하려는 설계 원칙과 연결됩니다.

`+`, `-`, `v/+` 같은 부호가 포함된 참조 문서도 올바르게 열립니다.

## AI는 임상가의 판단을 대신하지 않습니다

v2는 AI가 전문가를 대신해 판단하는 시스템이 아니라, 임상심리사와 수련생이 더 명확한 근거 위에서 검토하고 판단하도록 돕는 시스템을 목표로 합니다. 그래서 AI 기능은 두 가지로만 남겼습니다. 채점 화면에서는 코딩 도우미, 별도 채팅 화면에서는 해석 도우미입니다.

AI 답변은 참고와 보조를 위한 것이며, 최종 부호화와 해석은 임상가가 판단합니다.

## 보안과 개인정보

API 키와 AI 대화 원문은 장기 계정 자료로 보관되지 않습니다. API 키는 AI를 연결한 동안만 사용하며 로그아웃하거나 연결이 만료되면 삭제됩니다.

AI 사용 비용은 사용자가 연결한 API 제공자 계정에서 발생하며, 앱 자체의 결제나 구독 기능은 없습니다.

## 화면과 이용 편의

상단 메뉴, 언어 선택, 라이트·다크 모드, 계정 관리, 버전 아카이브와 참조 문서 검색 화면을 새롭게 구성했습니다.

채점 화면에서는 행 선택, 행 추가/삭제, 단축키, undo/redo 흐름을 정비했습니다. 선택된 행은 지속 강조 상태로 표시되며, 선택 상태에 따라 코딩 도우미가 받는 맥락도 달라집니다.

해석 도우미 화면에는 CSV 첨부 버튼과 드래그앤드롭 첨부를 추가했습니다. 단순히 텍스트를 붙여넣는 방식뿐 아니라, 구조요약 수치 CSV를 첨부하고 그 내용을 AI 대화 맥락으로 사용할 수 있습니다. 첨부 파일은 한 번에 하나만 받을 수 있도록 제한하여, 여러 자료가 섞여 AI가 잘못된 맥락을 읽는 일을 줄였습니다.

## 다국어 지원

v2는 한국어, 영어, 일본어, 스페인어, 포르투갈어 화면을 지원합니다. 언어는 드롭다운에서 선택할 수 있으며, 화면 크기와 언어별 문자열 길이가 달라도 배치가 안정적으로 유지됩니다.

## 제품 범위

v2.0.0의 핵심 범위는 구조요약 계산, 참조 문서, BYOK 기반 코딩 도우미와 해석 도우미입니다. 서비스가 제공하는 AI 크레딧, 결제나 구독 기능은 포함하지 않습니다.
