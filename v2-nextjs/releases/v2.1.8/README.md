# [2026-07-11] v2.1.8 버그 패치

## 먼저 확인하실 점

v2.1.8은 AI 도우미가 사용하는 다섯 언어 참조 문서 1,015개의 내용과 검색 방식을 개선한 패치입니다.

앱 화면은 변경하지 않았습니다. 계산기 자체의 수식이 아니라, 선택 기능인 AI 도우미가 질문과 관련된 문서를 더 잘 찾도록 개선했습니다.

## 핵심 변경

- 다섯 언어의 1,015개 참조 문서는 각 설명의 근거 강도와 한계를 함께 안내합니다.
- PTI, S-CON, DEPI, CDI, HVI, OBS 설명에 근거의 강도와 임상가가 반드시 확인해야 하는 한계를 명시했습니다.
- S-CON 양성만으로 위험을 단정하지 않고 직접적인 위험평가와 임상가 확인이 필요하다고 답하도록 했습니다.
- 다국어 검색에서는 악센트 유무와 관계없이 관련 문서를 함께 찾습니다.
- AI 도우미는 이 참조 문서를 바탕으로 질문에 답합니다.
- AI 도우미는 자연스러운 동의어를 이해하지만 진단 단정, 근거 없는 확정과 자동 적용은 피합니다.

## 남아 있는 한계

- 참조 문서와 AI 도우미는 임상적 판단을 대신하지 않습니다.
- 모델 응답에는 확률성이 있으므로 모든 미래 응답을 보증하지는 않습니다.
- 다섯 언어 문장은 참고용이며, 각 언어권의 공식 임상 번역을 대신하지 않습니다.
