# [2026-09-05] v2.2.13 버그 패치

## 주요 수정사항

### 개요

v2.2.13은 필수 채점값이 빠진 행이나 결정인과 형태질(FQ)이 맞지 않는 행이 계산에 포함되던 문제를 수정했습니다. 이제 이러한 입력이 있으면 계산을 멈추고 확인이 필요한 행을 안내합니다.

구조요약의 계산식과 특수지표 임계값은 바꾸지 않았습니다. 규칙에 맞게 완성된 기존 기록은 다시 계산할 필요가 없습니다. 다만 아래의 누락이나 불일치가 있었던 기록은 원자료를 확인하고 수정한 뒤 다시 계산해야 합니다.

### 세부사항

#### 필수 채점값이 빠진 행

반응의 부호화를 시작한 행에는 위치, 발달질(DQ), 결정인과 내용이 필요합니다. 이전에는 이 가운데 일부가 비어 있어도 계산이 진행될 수 있었습니다. 이제 누락된 항목이 있는 행을 안내하고, 입력을 완료할 때까지 계산하지 않습니다. 반응 메모를 새로 필수 항목으로 요구하지는 않습니다.

미완성 행이 실제 반응으로 집계되면 반응수(R)와 이를 사용하는 비율이 달라질 수 있습니다. 위치나 결정인이 빠진 경우에는 WDA%나 Lambda처럼 해당 부호를 사용하는 값도 영향을 받을 수 있습니다. 사용하지 않은 빈 행은 반응수에 포함하지 않습니다.

**예시: 한 카드에서 실제 반응이 없었던 경우**

예를 들어, 카드 VI에서 실제 반응이 없었다면 해당 행에 `none`이나 다른 부호를 입력하더라도 완성된 반응으로 처리할 수 없습니다. FQ의 `none`은 형태를 사용하지 않은 실제 반응을 나타내는 선택값이며, 반응이 없었다는 뜻으로 넣는 부호가 아닙니다.

그 행을 삭제하더라도 카드 VI에 실제 반응이 없었다는 사실은 바뀌지 않습니다. 카드 I–X에 각각 적어도 하나의 반응이 있어야 계산할 수 있다는 기존 기준은 그대로 유지됩니다. 원자료에 반응이 있는데 입력만 빠진 경우와 검사 당시 실제로 반응이 없었던 경우를 구분해 확인해야 합니다.

#### 결정인과 FQ가 맞지 않는 행

형태를 사용한 반응에는 그에 맞는 FQ를 기록해야 합니다. 예를 들어 순수 색채 결정인 `C`를 형태색채 결정인 `FC`로 바꾼 뒤에도, 앞서 설정된 FQ `none`이 남아 있는 문제가 있었습니다.

이제 형태를 사용하는 결정인으로 바꾸면 남아 있던 `none`을 미입력 상태로 되돌립니다. 반응기록과 질문단계(Inquiry)를 확인해 원반응에 맞는 FQ를 선택한 뒤 계산할 수 있습니다. 앱이 `o`, `u`, `-` 등의 값을 대신 추정하지는 않습니다.

기존 저장본 등에 결정인과 FQ의 불일치가 남아 있는 경우에도 확인할 행을 안내하고 계산을 멈춥니다. 이런 불일치는 형태질 집계, PTI의 일부 조건, 해당 반응의 GHR/PHR 분류에 영향을 줄 수 있습니다.

정상적인 무형태 반응은 계속 입력할 수 있습니다. 무형태 결정인만으로 이루어진 반응과 원전에서 인정하는 무형태 사람운동 반응에도 FQ `none`을 사용할 수 있습니다. `none`을 일괄적으로 금지하는 변경은 아닙니다.

## 기존 결과를 다시 계산해야 하나요?

- 필수 채점값이 모두 있고 결정인과 FQ가 일치하는 기록은 다시 계산할 필요가 없습니다.
- 누락된 필수 채점값이나 결정인과 FQ의 불일치가 있었던 기록은 반응기록과 질문단계를 확인하고 수정한 뒤 다시 계산합니다.
- 실제 반응이 없었던 카드는 임의의 부호를 채우거나 행을 삭제해 해결하지 않습니다. 원자료를 확인하고 기존 카드 I–X 입력 기준에 따라 처리해야 합니다.

이번 문제만으로 과거의 모든 계산 결과가 잘못됐다고 판단할 수는 없습니다. 영향을 받을 수 있는 입력 조건이 있었는지부터 확인해야 합니다.

## 근거와 임상적 한계

형태 사용 여부와 FQ의 관계는 Exner의 종합체계 원전에 근거합니다. 형태를 사용한 반응에는 FQ를 부여하며, 실제 무형태 반응과 무형태 사람운동은 구분해서 다룹니다. 반응의 부호별 빈도가 구조요약의 계산에 사용되는 방식과 GHR/PHR의 분류 순서도 함께 확인했습니다.

- Exner, J. E., Jr. (2003). *The Rorschach: A Comprehensive System, Volume 1: Basic Foundations and Principles of Interpretation* (4th ed.). Wiley. 인쇄 120쪽은 형태 사용 여부와 FQ, 143–144쪽은 GHR/PHR 분류, 151쪽은 R과 Lambda, 154쪽은 형태질 비율, 156쪽은 PTI 조건의 근거입니다.
- Exner, J. E., Jr. (2001). *A Rorschach Workbook for the Comprehensive System* (5th ed.). Rorschach Workshops. 인쇄 91–101쪽의 구조요약 작성 절차와 완성 사례를 참고했습니다.

누락·불일치가 있는 입력의 차단과 정상 무형태 반응의 허용을 확인했으며, 원전의 완성된 구조요약 사례는 기존과 같은 결과를 유지합니다. 다만 입력 검사를 통과했다는 사실이 개별 반응의 부호화가 임상적으로 정확하다는 뜻은 아닙니다. 최종 부호화와 해석에는 원반응, 질문단계와 전체 임상 자료를 검토하는 전문가의 판단이 필요합니다.

개인정보 처리 방식과 화면 배치, 입력 항목은 변경하지 않았습니다. 함께 사용하는 소프트웨어 구성요소의 보안 업데이트도 반영했습니다. 본 서비스는 전문가의 임상 판단을 대체하지 않습니다.
