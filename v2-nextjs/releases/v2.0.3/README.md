# [2026-06-11] v2.0.3 버그 패치

v2.0.3은 참조 문서 화면이 늦게 열리던 문제와 AI 연결 오류를 수정한 버그 패치입니다. 화면 구성, 사용 방식과 AI 답변 범위는 바뀌지 않았으며 참조 문서 화면은 더 빠르게 열리고 잘못된 AI 연결 정보는 안전하게 처리됩니다.

## 핵심 요약

- 참조 문서 화면이 더 빠르게 열립니다.
- 5개 언어 1,015개 공개 문서의 기존 주소는 그대로 유지됩니다.
- 잘못되거나 만료된 AI 연결 정보는 오류 화면 대신 연결되지 않은 상태로 안전하게 처리합니다.
- AI 연결 상태 확인 결과는 별도로 보관하지 않습니다.
- 당시 알려진 웹앱 보안 문제를 해결했습니다.

## 참조 문서 화면

v2.0.2까지는 회선 속도에 따라 참조 문서의 첫 화면이 늦게 나타날 수 있었습니다.

계산기, 구조요약 결과와 AI 대화 화면에는 영향이 없었고 참조 문서의 내용이나 링크도 바뀌지 않았습니다. 다만 회선 속도에 따라 참조 문서의 첫 화면이 늦게 나타날 수 있었습니다.

## 달라진 점

참조 문서 화면이 더 빠르게 열리며, 기존 공개 문서 주소는 그대로 유지됩니다.

잘못되거나 만료된 AI 연결 정보는 오류 화면을 띄우지 않고 연결되지 않은 상태로 처리합니다. AI 연결 상태 확인 결과는 별도로 보관하지 않습니다.

당시 알려진 웹앱 보안 문제를 해결했습니다.
